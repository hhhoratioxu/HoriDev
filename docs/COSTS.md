# 用量与内部预算

## 默认值

| 控制项                 | 默认            |
| ---------------------- | --------------- |
| 总测试预算             | $47             |
| 软预算提醒             | $35             |
| 硬预算阈值             | $42             |
| 安全预留               | $5              |
| 默认单用户累计额度     | $3              |
| 每任务累计上限         | $0.75           |
| 平台同时付费调用       | 2               |
| 同一用户同时付费调用   | 1               |
| 同一项目同时运行阶段   | 1               |
| 每任务最多模型阶段调用 | 6（含失败尝试） |

管理员可以修改这些应用设置，软预算 ≤ 硬预算，硬预算 + 安全预留 ≤ 总预算。实时模式还有 LIVE_CALLS_ENABLED 运营开关、维护模式、AI 总开关和人工订单授权。

预算只覆盖本应用账本。用户提供的“约 $47 额度”没有通过账单接口验证；新建密钥和本应用数据库不会自动同步整个 OpenAI 账户的历史账单、其他密钥或其他应用的消耗。

## 价格与计算

默认标准处理价格核对于 2026-10-29 的官方模型页，单位为每百万 Token 的 USD：

| 模型        | 输入 | 缓存输入 |  输出 |
| ----------- | ---: | -------: | ----: |
| gpt-6-luna  | 0.10 |     0.01 |  0.50 |
| gpt-6.1-sol | 2.00 |     0.10 | 10.00 |

[GPT-6 Luna 价格](https://developers.openai.com/api/docs/models/gpt-6-luna)、[GPT-6.1 Sol 价格](https://developers.openai.com/api/docs/models/gpt-6.1-sol)。账号是否可以调用，必须另行验证。

每次预留时保存价格快照；管理员期间修改价格不会影响该次请求的结算。官方完成、失败或截断事件中的 usage 是 Token 来源。金额为：

```text
USD = ((input_tokens - cached_tokens) × input_price
       + cached_tokens × cached_price
       + output_tokens × output_price) / 1,000,000
```

金额以整数微美元向上取整。输出 Token 包含 API 统计中的推理等输出用量，不用可见文本长度冒充实际消耗。未返回官方 usage 的请求不推造 Token。

请求设置 store:false 和 stream:true，没有额外付费工具。每阶段输出上限：分析 3000、生成 12000、审查 4000 Token。输入预留按 UTF-8 字节数保守估算，并加入 schema/envelope、缓存写入和价格安全余量。应用估算不保证覆盖所有将来的价格变化、服务档位、区域附加费或平台账单差异；请在启用 Live 前核对适用价格。

## 原子预留与并发

任务首先通过比较旧状态/calls 获取独占 run_id。随后一条 INSERT…SELECT 语句在 D1 主数据库中同时检查平台、用户、任务累计已结算+预留、平台并发、单用户并发和调用次数；只有满足全部条件才创建 reserved 账本。SQLite/D1 写入串行化，因此两个请求不会同时使用同一旧余额通过检查。

如果预算或并发检查失败，任务认领会回滚为原状态，calls 不消耗。实际提交模型的尝试计入有限次数。SDK 自带重试关闭，只有明确的 429 拒绝最多重试一次；网络中断与未知结果不会自动重试。

完成或收到已知 usage 后结算并释放剩余预留。结构校验失败、输出被截断或保存失败仍会记录已知实际 usage，不会把 API 已消耗的部分退成零。

## 取消、超时与未知用量

取消请求设置服务端标志，运行器轮询并中止上游流。上游可能已计费，不能承诺取消免费。

未收到 usage 时，明确 400/401/403/404/429 拒绝可释放预留；网络错误、断线、超时、运行器退出等保留 uncertain 费用占用。未知记录不再占用运行并发，但金额继续计入所有预算。停滞超过 4 分钟的任务可通过恢复接口转为失败并保留预留。

管理员在 OpenAI 账单/请求记录中核对后，可填写人工金额和依据。此类账本状态为 manual，保留审计说明，Token 仍保持未知，不被标为官方 usage。恢复任务或再次请求是新的资源消耗，仍受预算限制。

## 云服务费用

Workers、D1 和可选 R2 与 OpenAI 分别计费。内部 $47 控制仅针对 AI 估算，不覆盖 Cloudflare 账单。免费额度、CPU 和存储限制会随计划变化，部署前以当前账户与官方价格为准。
