# 安全设计与上线边界

## 已实现

- Better Auth 维护密码哈希、会话、登录/退出、密码更改和会话撤销。数据库通过 Drizzle 的 SQLite 适配器连接 D1，未使用 D1 不支持的交互事务。
- 生产 Cookie 为 HttpOnly、Secure、SameSite=Lax；管理员使用额外的 SameSite=Strict 签名 Cookie，绑定用户和当前登录会话，15 分钟过期。管理员 ID 来自服务端白名单，角色字段不接受注册输入。
- 所有私有项目、任务、文件、下载和导出接口都进行服务端身份与所有权检查。无权访问与不存在资源统一返回 404。
- 所有写请求验证精确 Origin 并要求 JSON。Better Auth 自身也验证 trustedOrigins。生产不开放通配跨域；APP_URL 必须为真实 HTTPS 源。
- Better Auth 登录和注册限流使用 D1 中的原子 consume 计数；普通 API、管理解锁也有服务端速率限制。生产仅信任 Cloudflare 的 cf-connecting-ip，不信任任意转发链。
- OpenAI 密钥仅存在服务端 Secret 或被 Git 忽略的本地文件。前端没有密钥配置入口，不会将服务端 Env 放入提示词。统一日志只记录请求 ID、阶段、模型、错误分类等有界元数据，对疑似密钥和 Bearer 做脱敏。
- 模型不获得工具、shell、文件系统或网络能力。用户代码和历史消息仅作为不可信文本进入有界提示；没有 eval、子进程或动态执行客户程序。
- 模型结构化输出经过 Zod、相对路径、扩展名、数量、UTF-8 大小、重复路径校验。拒绝路径穿越、反斜杠、控制字符、百分号编码、敏感配置文件名和 .git 路径。
- 文件保存采用版本比较与唯一索引，避免静默覆盖。项目有 AI 阶段运行时拒绝手工文件写入。阶段结果采用 D1 原子 batch；取消标志与 run_id 条件阻止迟到结果提交。
- React 默认转义消息与源码，无 raw HTML 消息渲染。HTML 预览使用无权限 sandbox iframe 及内嵌 CSP，禁止脚本、网络、表单、导航能力和弹窗。下载为 attachment + nosniff。
- 静态资源使用 CSP、Frame 防护、Referrer 与 Permissions Policy。Monaco 编辑器和 Worker 资源由本站提供，不从 CDN 加载。
- 费用账本包含调用前预留、价格快照、实际 API usage、未知费用预留、人工核对和管理员审计。平台、用户、任务、并发与调用次数检查都在服务端。

## 当前上线范围

首版适合本地验收和受邀试运行。生产默认关闭注册。公开收费服务还需要邮件验证/找回、MFA 或更强管理员验证、Turnstile 或等效滥用防护、持续依赖审计、备份/恢复演练、隐私与删除流程、付款/退款合规以及实际负载测试。

邮箱尚未验证，因此不能把邮箱身份视为已认证的外部身份，也不能按邮箱域名自动授权。没有预置管理员账号或密码。管理员初始化通过已注册用户 ID 白名单完成。

密码哈希使用认证库的成熟实现，可能超过 Workers 免费计划的 CPU 预算。应在实际 Cloudflare 账户上测量 CPU；若需要付费计划，应先获得运营方授权。本地认证成功不能证明免费云计划下的稳定性。

Prompt Injection 无法仅靠提示完全消除。此版本通过不给模型服务端执行工具、不发送秘密、校验输出和保留人工审查来降低影响。用户仍不能上传秘密、敏感数据或无权使用的源码。

## 数据与容量

- 50 项目、200 任务的账号上限用于约束 MVP 数据规模；生产应增加真正的分页、配额及归档。
- 当前文件最多 20 个，单文件 100 KB，源码合计 500 KB，模型输入最多 60 KB。文件版本占用和 D1 总容量需要运营监控，当前没有自动历史压缩。
- 真实计费记录暂时阻止项目删除，以保持核账链。正式服务必须规定保留周期并支持经授权的隐私删除或去标识化。
- R2 桶保持私有，ZIP 副本建议配置生命周期。D1 和 R2 是不同备份对象。
- 应用不提供任意 URL 抓取或 OpenAI base URL 配置，避免由用户输入引导服务端读取内部网络。

## 开发与生产

本地 `.dev.vars`、`.env*`、`.wrangler/` 均不提交。生产使用独立数据库和 Secret。部署脚本要求显式 production 配置；示例 UUID/域名会触发失败。当前没有执行任何生产部署。

Cloudflare 与 OpenAI 的实际地区可用性、账号权限及政策适用性由运营方确认，不能假定换部署区域就可以绕开限制。

参考：[Better Auth Drizzle 适配器](https://better-auth.com/docs/adapters/drizzle)、[原子速率限制](https://better-auth.com/docs/concepts/rate-limit)、[D1 API](https://developers.cloudflare.com/d1/worker-api/d1-database/)。
